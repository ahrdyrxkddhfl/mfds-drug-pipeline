# mfds-drug-pipeline

식약처 공공 API 기반 의약품 마스터 데이터 파이프라인

## 개요

식품의약품안전처가 제공하는 의약품 허가정보 및 회수·판매중지 정보를
수집·정제·검증하여 조회 가능한 형태로 제공하는 데이터 파이프라인입니다.

공공 API의 원본 데이터에는 표기 불일치, 중복 레코드, 결측 등의
품질 이슈가 존재하며, 이를 탐지하고 정규화하는 과정을 자동화합니다.

## 데이터 소스

| 소스 | 설명 | 규모 |
|---|---|---|
| 의약품 제품 허가정보 | 품목별 허가 현황 | 약 43,000건 |
| 의약품 회수·판매중지 정보 | 회수·판매중지 이력 | 확인 예정 |

## 기술 스택

- Python
- PostgreSQL
- Apache Airflow
- FastAPI
- Docker Compose
